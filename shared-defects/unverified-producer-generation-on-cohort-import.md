title: Cohort import can trust stale generated producer output
severity: major
affected_layer: harness
impact_scope: >-
  Confirmed for the new four-form workbench cohort importer. The producer Git
  HEAD and tracked sources are pinned, but ignored or untracked dist output can
  be stale or tampered unless generation is executed or cryptographically
  verified during import. Every future imported cohort would inherit this
  provenance risk.
owner: Codex-producer-cohort-agent
superbee_progress_status: fixing
superbee_updated_by: Codex
---
The importer records exact generated bytes and tracked source hashes but initially relies on caller-prepared dist output. Pinning tracked HEAD does not prove those generated bytes came from the pinned source. The importer must execute the configured generator non-interactively from the pinned clean checkout, or verify an authoritative producer-generated manifest, then recheck tracked cleanliness and translate dependency failures without raw output leakage.
